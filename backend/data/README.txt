Default training data
----------------------
sgcc.csv is the user's datasetsmall.csv (25,863 rows; 26 daily-reading columns + CONS_NO + FLAG).
It is included so the project can start without manually placing a dataset.

For training with the full dataset, replace this file with the user's `data set.csv` and name it `sgcc.csv`.
Keep the exact columns CONS_NO and FLAG, plus date-named daily consumption columns.
